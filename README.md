# hideout

React 18 + Vite + TypeScript (strict) frontend for hideout-api.

## Setup

```sh
npm install
cp .env.example .env.local   # then fill in real values
npx playwright install chromium   # once, for e2e
npm run dev
```

## Scripts

| Script | What it does |
| --- | --- |
| `npm run dev` | Dev server on http://localhost:5173 |
| `npm run build` | Typecheck and production build |
| `npm run typecheck` | `tsc -b` only |
| `npm run lint` | oxlint |
| `npm test` / `npm run test:run` | Vitest (watch / once) |
| `npm run test:e2e` | Playwright |
| `npm run gen:api` | Regenerate `src/lib/api/schema.gen.ts` from hideout-api's OpenAPI spec |

## Layout

- `src/routes/`: TanStack Router file-based routes. `src/routeTree.gen.ts` is generated by the Vite plugin; commit it.
- `src/components/ui/`: shadcn/ui components. Add more with `npx shadcn@latest add <name>`.
- `src/features/`: feature components.
- `src/lib/`: `env` (Zod-validated env vars), `api/client` (openapi-fetch), `http` (axios), `supabase` (read-only), `query-client`.
- `src/stores/`: Zustand stores for UI state that outlives a route.
- `src/test/`: Vitest setup and MSW handlers. `e2e/`: Playwright specs.

## Conventions

- Server data goes through TanStack Query. Zustand is for client-only UI state.
- Forms use react-hook-form + Zod, with shadcn's `Field` components and RHF's `Controller`.
